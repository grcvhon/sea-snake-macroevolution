# sea-snake-macroevolution
This repository contains input data and R code used in the manuscript: Using a null hypothesis framework to test expectations of disparity in an adaptive radiation.

The maximum clade credibility (MCC) tree, 500 samples tree, and morphological trait dataset were obtained from Sherratt E, Rasmussen AR, Sanders KL. 2018 Data from: Trophic specialisation drives morphological evolution in sea snakes. , 1031807 bytes. (https://datadryad.org/dataset/doi:10.5061/dryad.48r5h).
