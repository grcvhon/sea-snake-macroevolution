# sea-snake-macroevolution
This repository contains data and R code used in the manuscript: Using a null hypothesis framework to test expectations of disparity in an adaptive radiation (Garcia et al. in prep).

The maximum clade credibility (MCC) tree, 500 samples tree, and morphological trait dataset (body shape and body size) were obtained from Sherratt E, Rasmussen AR, Sanders KL. 2018 Data from: Trophic specialisation drives morphological evolution in sea snakes. , 1031807 bytes. (doi:10.5061/DRYAD.48R5H)
